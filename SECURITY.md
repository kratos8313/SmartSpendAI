# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository. Include reproduction steps, the affected version, impact, and any suggested mitigation.

Do not include real financial records, credentials, Firebase configuration from a private project, receipt images, or authentication tokens in a report.

## Deployment responsibilities

Operators must deploy the repository's Firestore rules, restrict Firebase project access, protect release signing material, configure usage alerts, and keep dependencies and Android target levels current.
